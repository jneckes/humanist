Editing

In Edit mode, when the text you change already uses curly quotes or apostrophes, the straight ones you type are converted to match. Nothing else changes.

Trusted folders

Files in these folders open Trusted, even when they came from the internet. A file you open with File › Open in Protected View still opens Protected.

    Untrusted folders

    Files in these folders open in Protected view, even when they did not come from the internet.

      Network in Protected view

      Also blocks the fonts, styles, scripts and images Protected view otherwise loads from the CDN allowlist.

      CDN allowlist

      In Protected view, documents may load fonts, styles, scripts and images (GET only) from these hosts. A request to one of them can still carry data in its address.
