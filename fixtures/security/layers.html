Protected network layers

9.9 Network policy, Protected: three layers stop a Protected deck's network use. connect-src 'none' (the CSP) stops fetch, XHR, EventSource, WebSocket and sendBeacon for every origin, blueline:// included; onBeforeRequest (the requests layer) cancels http(s) and ws(s) requests and blueline:// fetch, XHR and beacons; the closed-port proxy stops connections that escape both. The security suite opens this page Protected with two layers turned off at a time (BLUELINE_TEST_DISABLE_LAYER), so each layer is checked on its own, and with all three off as the positive control.
